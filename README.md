## 🚀 Setup

### 1. Clone the repository

```bash
git clone https://github.com/SofieVerhoeven/Gamejam-2026.git
```
### 2. Navigate to the project folder
```bash
cd Gamejam-2026
```
### 3. Install dependencies
```bash
npm install
```

## 🎮 Development

To start the development server:
```bash
npm run dev
```
To stop the development server:
```bash
Ctrl + C
```
